# APC-II

Repositório dedicado à disciplina **Algoritmos e Programação de Computadores II** (APC-II).  
Aqui estão reunidos todos os exercícios e projetos desenvolvidos durante o semestre, utilizando a linguagem **C**.

## 📚 Conteúdo
- Exercícios de fixação  
- Listas de atividades  
- Projetos práticos  
- Exemplos de código  

## 🛠 Linguagem
- **C**

## 🚀 Como executar os códigos
1. Certifique-se de ter um compilador C instalado (por exemplo, [GCC](https://gcc.gnu.org/)).
2. Compile o arquivo desejado:
   ```bash
   gcc nome_do_arquivo.c -o nome_do_programa
3. Execute o programa:
   ```bash
   ./nome_do_programa
